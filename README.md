## What it does
<p>This is a very simple task manager, that runs in your browser.</p>
<p>You can host it locally or on a webspace.</p>
<p>All data is stored locally in your browser's indexedDB. So there are no privacy issues. There is no data synchronization built-in. But there is an export and import feature in place.</p>
<p>There is a toggle for dark and light view as well as big and normally sized fonts.</p>
<p>The editor is [easyMDE](https://github.com/ionaru/easy-markdown-editor). I've added a dialog for image URLs. And you can insert local images as well (webp, jpeg, png).</p>

## How to get started
<p>Copy the three files (index.html, styles.css and app.js) somewhere and open index.html in your browser.</p>
